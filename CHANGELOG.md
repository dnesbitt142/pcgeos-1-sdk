# Changelog

## 0.1 - 2026-09-25

Initial experimental release.

- GEOS 1.x/2.x executable parser with bounds and relocation checks.
- GeoWorks Pro 1.2 target scanner and exact-template fingerprinting.
- Linux GNU GCC/binutils build path.
- Cross-platform LLVM build path intended for Linux and native Windows.
- Native 1.x Primary + GenView + title-bar Help application template.
- Freestanding C API for drawing, keyboard and pointer callbacks.
- 386+ private-stack/scheduler bridge for modern GCC/Clang-generated code.
- GEOS 1.x geode resource and relocation packer.
- Minimal Hello application and advanced MiniCalc reference source.
- Documentation of recovered native UI, file-selector and file-I/O techniques.

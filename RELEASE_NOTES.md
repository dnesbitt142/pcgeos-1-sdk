# PC/GEOS 1.x SDK 0.1 Release Notes

SDK 0.1 is the first packaged release of the modern-host experimental build method developed while extending GeoWorks Pro / Ensemble 1.x applications.

## Highlights

- modern Linux GCC and cross-platform LLVM compiler pipelines;
- genuine GEOS 1.x geode packaging;
- native 1.x primary window, view and title-bar Help template;
- bounds-checked geode inspection and target inventory;
- 386+ scheduler/register bridge for modern compiler output;
- reproducible minimal example;
- advanced MiniCalc reference with native menus, file selectors, in-cell editing and file services;
- comprehensive reverse-engineering and portability documentation.

## Validation

The bundled Hello self-test was built successfully with both GNU GCC/binutils and LLVM/Clang/LLD against the known target archive. Both outputs parse as GEOS 1.x applications with kernel protocol 622.3, UI protocol 693.0, 12 resources and 41 relocation records.

The LLVM path was validated on Linux. The Windows PowerShell/native-LLVM launcher is included but requires confirmation on a real Windows host.

## Not yet provided

- historical 8086/286 C compilation;
- full Object Assembly/GOC language support;
- general UI class definitions;
- public stable file-I/O API;
- multiple target profiles;
- live runtime certification for every generated application.
